# SidStation ASID 1.1.1

> **macOS: use [1.1.2](https://github.com/benjamindehli/sidstation-asid/releases/tag/v1.1.2) instead.** The macOS package failed to build for this release, so no DMG was attached to it. 1.1.2 is the same plugin with that build fixed. The Linux and Windows downloads here are complete and identical to 1.1.2.

A fix release. Most of it is about notes that came out silent, which was the main thing wrong with 1.1.0 in real use. There are no new features and no new parameters, so presets and automation from 1.1.0 carry over unchanged.

## Fixed

- Notes dropping out on fast passages with a high decay. The 6581 envelope shares one rate counter, and a quick retrigger could arrive while it was parked, so the attack waited for the counter to come round and the note was silent. Handled now in three ways that work together: decay is sent as 0 at full sustain, where it is inaudible anyway, the envelope is drained before a fresh attack that lands while a previous note is still releasing, and the envelope is parked once its fade has finished so the next attack never has to wait.
- Muted notes on legato and on quick re-attacks. A note landing on an oscillator that is already sounding now retunes rather than retriggering, so the rate counter is not reloaded and the note cannot stall.
- Pitch modulation stopping during the envelope's release. Vibrato and glide kept running into the release tail instead of freezing the fading note at whatever pitch was last written.
- Tempo synced LFOs drifting. Cycle boundaries are counted from the song position rather than inferred from the phase moving backwards, so a looping transport no longer confuses them.
- The editor zeroing the decay parameter at full sustain. It now leaves your value alone and shows the control as inactive, so lowering sustain again gives you the decay you set.
- Preset names are sanitised before being used as filenames, so a name with a slash or a colon in it can no longer write outside the presets folder or fail to save.
- MIDI frames queued while no output port is open are dropped rather than held, so opening a port no longer flushes a burst of stale frames at the unit.
- A crash on shutdown in some hosts, from the interface's look and feel being destroyed while still in use.
- A race in the shared state between plugin instances, which are now notified with the lock held.

## Also

- Parameter lookups are cached off the audio thread, which takes work out of the audio callback.
- Unused MIDI receive and bulk send paths were removed from the device layer. The protocol side of that work still lives in `core/` and is exercised by `probe/` and the core tests.

## Install

- macOS: download the DMG and run the installer inside. Universal for Apple Silicon and Intel, signed and notarized.
- Windows: download the setup .exe and run it. It is unsigned, so Windows SmartScreen shows a warning on first run (choose More info, then Run anyway). The VST3 goes in Common Files\VST3 and the Standalone in Program Files.
- Linux: download the .tar.gz and extract it. Copy the .vst3 into ~/.vst3 and run the Standalone. See INSTALL.txt inside the archive.

## Requirements and notes

- macOS 10.15 or later. Windows and Linux are x86_64.
- Enter ASID mode on the unit's front panel before playing.
- Developed and tested against OS 1.11 R34 hardware on macOS. The Windows and Linux builds compile and package but are not yet hardware-tested.
- A high decay with sustain below 15 can still drop notes on fast parts. The decay is audible there so it cannot be zeroed for you, and it remains a limit of the chip. Keeping decay lower on fast passages is the workaround.
