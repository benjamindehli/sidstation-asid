# SidStation ASID 1.2.1

A fix release. Every note played about a quarter of a semitone sharp, and Logic Pro reported a crash each time it was closed with the plugin loaded. Both are fixed. There are no new features and no new parameters, so presets and automation from 1.2.0 carry over unchanged.

## Fixed

- **Tuning.** Every note played about 26 cents sharp, on every voice and waveform, with or without pitch modulation. Notes were converted to SID frequency values using the clock of a PAL Commodore 64, which runs at 985248 Hz, but the SidStation runs its SID at 1 MHz. With Coarse and Fine centred, A4 now plays at 440 Hz. Thanks to the user who reported it.
- **Logic Pro quitting unexpectedly on close.** Two bugs in JUCE, the framework the plugin is built on, made Logic report a crash every time it was closed with the plugin loaded. JUCE 9.0.4 fixes the first. The second is a MIDI callback that could still run after the plugin's objects were torn down at exit. A small local patch to JUCE fixes it until JUCE does, and it has been [reported upstream](https://github.com/juce-framework/JUCE/issues/1776). Your projects were never at risk, since the crash happened after Logic had finished closing them.

## Also

- If you tuned a preset by ear to make up for the old offset, it now plays about a quarter of a semitone flat. Raising its Fine control by 26 cents restores the old pitch.
- The plugin is now built on JUCE 9.0.4, up from 8.0.15.

## Install

- macOS: download the DMG and run the installer inside. Universal for Apple Silicon and Intel, signed and notarized.
- Windows: download the setup .exe and run it. It is unsigned, so Windows SmartScreen shows a warning on first run (choose More info, then Run anyway). The VST3 goes in Common Files\VST3 and the Standalone in Program Files.
- Linux: download the .tar.gz and extract it. Copy the .vst3 into ~/.vst3 and run the Standalone. See INSTALL.txt inside the archive.

## Requirements and notes

- macOS 10.15 or later. Windows and Linux are x86_64.
- Enter ASID mode on the unit's front panel before playing.
- Developed and tested against OS 1.11 R34 hardware on macOS. The Windows and Linux builds compile and package but are not yet hardware-tested.
- JUCE 9 changed how Windows sends SysEx, which carries every ASID frame. If ASID timing on Windows sounds different from 1.2.0, please open an issue. Reports from Windows users with a SidStation are very welcome.
- A synced wavetable step still turns over on a tick of the Clock in the top strip, so a step shorter than one tick cannot be played in full. 1/64 starts skipping above roughly 94 BPM on Eco 25 Hz and 188 BPM on PAL 50 Hz, while HiFi 100 Hz keeps it clean to 300.
- A high decay with sustain below 15 can still drop notes on fast parts. The decay is audible there so it cannot be zeroed for you, and it remains a limit of the chip. Keeping decay lower on fast passages is the workaround.
