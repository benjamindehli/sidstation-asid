# SidStation ASID 1.1.0

This release adds Windows and Linux builds alongside the macOS release. The plugin and its features are unchanged from 1.0.0.

## New

- Windows: a setup installer (Inno Setup) that installs the VST3 and Standalone.
- Linux: a tarball with the VST3 and Standalone plus install notes, for x86_64.

## Install

- macOS: download the DMG and run the installer inside. Universal for Apple Silicon and Intel, signed and notarized.
- Windows: download the setup .exe and run it. It is unsigned, so Windows SmartScreen shows a warning on first run (choose More info, then Run anyway). The VST3 goes in Common Files\VST3 and the Standalone in Program Files.
- Linux: download the .tar.gz and extract it. Copy the .vst3 into ~/.vst3 and run the Standalone. See INSTALL.txt inside the archive.

## Requirements and notes

- macOS 10.15 or later. Windows and Linux are x86_64.
- Enter ASID mode on the unit's front panel before playing.
- Developed and tested against OS 1.11 R34 hardware on macOS. The Windows and Linux builds compile and package but are not yet hardware-tested.
