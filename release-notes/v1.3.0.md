# SidStation ASID 1.3.0

This release adds MIDI Learn, Undo and Redo, a resizable window and an opt-in check for new versions, and names every control for screen readers. It also fixes a crash in hosts that unload the plugin while they keep running.

No parameters were added, removed or renamed, so presets and automation from 1.2.1 carry over unchanged.

## New

- **MIDI Learn.** Right-click a control (or Ctrl-click on a Mac) and choose Learn MIDI CC, then move a knob or fader on your controller. While it waits, the control flashes and the preset bar says so, with a Cancel button, and Esc cancels too. The same menu shows the learned CC and can forget it. Learned controllers are saved with the session. The mod wheel and the channel mode messages (CC 120 to 127) are never learned, and controller moves are not undo steps.
- **Undo and Redo**, as buttons in the preset bar and on Cmd+Z and Shift+Cmd+Z (Ctrl on Windows and Linux). Each knob move, switch press, preset load and Init is one step. Automation and changes made in another instance are not recorded, and opening a saved session starts a new history.
- **A resizable window**, from its natural size to twice that, keeping its shape. Drag the grip in the bottom-right corner or the window's edge. The size is saved with the session.
- **An opt-in check for new versions.** The first time the window opens, the preset bar asks whether it may check for a new version when the window opens. If you allow it, it reads one small file from the project's website and sends nothing about you. A newer release then shows at the right end of the bar, and clicking it opens a menu with the release page and the setting.
- **The version number** at the right end of the preset bar, so it can be read off when reporting a problem.
- **Names for screen readers** on every control. A control set by a parameter is read out by the parameter's name, the same name hosts show for automation, and the voice switch can now be reached and set from a screen reader as well as with the mouse.

## Fixed

- **A crash in hosts that unload the plugin while they keep running**, as FL Studio and Reaper do on Windows once no instance is left. The stuck-note watchdog and the MIDI sender kept running in the unloaded plugin. The state the instances share now lives as long as any instance does, and the last one to close stops both and closes the MIDI port.
- **A damaged session or preset.** A saved value that is not a number, as a damaged or hand-edited file can hold, was handed on to the host and the SID. Such a value now goes back to its control's default when the session or preset loads.

## Also

- Hover hints and the value readout shown while turning a knob are now plain boxes in the C64 colours instead of speech bubbles, and a hint for a control at the edge of the window stays inside it. The hint for the version number was half cut off.
- The plugin is now built on JUCE 9.0.6, up from 9.0.4. It includes the fix for the second cause of Logic Pro quitting unexpectedly, which 1.2.1 worked around with a local patch to JUCE. That patch is gone.

## Install

- macOS: download the DMG and run the installer inside. Universal for Apple Silicon and Intel, signed and notarized.
- Windows: download the setup .exe and run it. It is unsigned, so Windows SmartScreen shows a warning on first run (choose More info, then Run anyway). The VST3 goes in Common Files\VST3 and the Standalone in Program Files.
- Linux: download the .tar.gz and extract it. Copy the .vst3 into ~/.vst3 and run the Standalone. See INSTALL.txt inside the archive. The version check needs libcurl, which most systems already have.

## Requirements and notes

- macOS 10.15 or later. Windows and Linux are x86_64.
- Enter ASID mode on the unit's front panel before playing.
- Developed and tested against OS 1.11 R34 hardware on macOS. The Windows and Linux builds compile and package but are not yet hardware-tested.
- A synced wavetable step still turns over on a tick of the Clock in the top strip, so a step shorter than one tick cannot be played in full. 1/64 starts skipping above roughly 94 BPM on Eco 25 Hz and 188 BPM on PAL 50 Hz, while HiFi 100 Hz keeps it clean to 300.
- A high decay with sustain below 15 can still drop notes on fast parts. The decay is audible there so it cannot be zeroed for you, and it remains a limit of the chip. Keeping decay lower on fast passages is the workaround.
