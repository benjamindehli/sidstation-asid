# SidStation ASID 1.2.0

This release makes the wavetable tempo aware, and fixes modulation that stopped partway through a long release.

Two parameters were added, so presets and automation from 1.1.2 carry over unchanged. A preset saved before this version loads with the wavetable's Sync off, which is exactly how it behaved.

## New

- **BPM Sync on the wavetable.** A step can last a note division at the host tempo instead of a number of frames, so an arpeggio table keeps its timing when the tempo changes. The Rate control becomes the division while Sync is on, reading as 1/16 and so on, and the table still restarts from step 0 on each note-on, the way a tracker table and an arpeggiator do. In the standalone, or in a host that reports no tempo, it follows the BPM field in the top strip.
- **Two shorter divisions, 1/32 and 1/64**, on the wavetable and on the three LFOs. A wavetable step is far shorter than an LFO cycle, and 1/64 at 120 BPM is a 31 ms step, the same territory as the 20 ms PAL frame the technique was built around.

## Fixed

- Modulation stopping partway through a long release. Vibrato and the wavetable ran for only the first four seconds of the envelope's fade, so with release 13, 14 or 15, which fade for 9, 15 and 24 seconds, the movement froze while the note was still clearly sounding. Both now run for as long as there is something to hear.
- The wavetable stopping on whichever step a note-off landed on, rather than playing on through the fade like the rest of the voice. Its arpeggio offset was dropped at the same moment, so a note released on an offset step snapped back in pitch as it faded.

## Also

- The wavetable's Speed control is now called Rate, matching the LFOs. Only the label changed, so automation and presets that used it carry over.

## Install

- macOS: download the DMG and run the installer inside. Universal for Apple Silicon and Intel, signed and notarized.
- Windows: download the setup .exe and run it. It is unsigned, so Windows SmartScreen shows a warning on first run (choose More info, then Run anyway). The VST3 goes in Common Files\VST3 and the Standalone in Program Files.
- Linux: download the .tar.gz and extract it. Copy the .vst3 into ~/.vst3 and run the Standalone. See INSTALL.txt inside the archive.

## Requirements and notes

- macOS 10.15 or later. Windows and Linux are x86_64.
- Enter ASID mode on the unit's front panel before playing.
- Developed and tested against OS 1.11 R34 hardware on macOS. The Windows and Linux builds compile and package but are not yet hardware-tested.
- A synced wavetable step still turns over on a tick of the Clock in the top strip, so a step shorter than one tick cannot be played in full: the table crosses whole steps between ticks and a step crossed that way is never sent to the chip. 1/64 starts skipping above roughly 94 BPM on Eco 25 Hz and 188 BPM on PAL 50 Hz, while HiFi 100 Hz keeps it clean to 300. The Rate control says so in its hover hint while it is happening.
- A high decay with sustain below 15 can still drop notes on fast parts. The decay is audible there so it cannot be zeroed for you, and it remains a limit of the chip. Keeping decay lower on fast passages is the workaround.
