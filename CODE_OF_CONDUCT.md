# Code of conduct

## The short version

Be decent to people. Assume they are trying to help. Argue about the code rather than about each other.

## What is expected

Take the other person seriously. Someone reporting a bug that turns out to be their own MIDI routing has still spent their evening trying to make this work, and a beginner's question about the SID chip is not a waste of anyone's time.

Say what you know and say what you do not. A lot of this project is findings from a single unit on one firmware version, and the difference between "this is how the hardware behaves" and "this is what my unit did" is one people here care about. Overstating what you have verified is the failure mode this project actually suffers from.

Take disagreement about technical decisions as normal. Disagree, give reasons, and accept that the maintainer will sometimes decide the other way.

## What is not

Harassment, insults, and personal attacks. Sexual language or imagery, and unwelcome attention of any kind. Demeaning people over anything about who they are, including their experience level. Publishing anyone's private information. Sustained disruption of a discussion.

None of that is welcome, in issues, in pull requests, in commit messages, or anywhere else this project is discussed.

## Scope

This applies anywhere the project is happening, and when someone is representing the project elsewhere.

## If something goes wrong

Report it through [dehlimusikk.no](https://www.dehlimusikk.no/#contact), to Benjamin Dehli, who maintains the project. Reports stay private. You will get a reply, and you will not be pressed to interact with whoever the report is about.

Whoever reports something is not thereby obliged to explain, justify or educate. If you are on the receiving end of a report, the expectation is that you listen rather than litigate.

The maintainer will do what seems proportionate, up to and including removing comments, closing contributions, and blocking accounts. A single maintainer deciding these things is not an ideal arrangement and it is the arrangement this project has, so it will be applied as evenly as possible, and being a frequent contributor will not earn anyone more latitude.
